智慧引才图谱 · 整体系统架构（一期 MVP）

单体优先 · AI 全内网化 · 演示主线：上传 → 解析 → 匹配 → 推送 → 导出

数据流（演示主线）

步骤说明关键模块
1. 上传解析批量上传 PDF/Word/图片 → 文本提取（扫描件走 OCR）→ LLM 结构化抽取（带置信度）→ 生成向量入库parser · llm · embedding
2. 岗位结构化对话式自然语言需求 → LLM 拆成硬性条件（学历/专业/年龄）+ 择优条件（方向/技能/履历/意愿）llm
3. 两级匹配第一级硬性过滤（规则，绝不误杀）→ 第二级向量粗排 Top30 → LLM 精排 Top10 并逐条生成理由matching · pgvector · llm
4. 推送与反馈HR 复核精选后推送（简历状态→已推送）→ 单位一键反馈（被选中/未选中回退在库）match 路由 · 状态机
5. 导出精选名单导出 Excel（含分数、向量相似度、匹配理由）exporter

边界与降级设计

设计说明
AI 全内网化LLM 走内部平台内网 API；Embedding 优先平台接口、缺失时本地 BGE-M3；OCR 本地 PaddleOCR；全程不出内网
稳定性兜底LLM 调用失败重试 3 次 + 指数退避；平台不支持 JSON 模式时自动降级；抽取带置信度、低置信字段人工修正后入库
SQLite 演示模式DATABASE_URL=sqlite:///... 时无需 PostgreSQL 即可跑通全流程（向量检索退化为 Python 计算），便于本机快速演示
人机边界AI 只做初筛与排序；最终推荐由 HR 复核精选，AI 不直接对外发送任何结果
